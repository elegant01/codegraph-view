CodeGraph 可视化 · 使用说明

      
    

    

      
快速上手

      
顶部输入 符号名（如 getRoomList）或 接口 URL（如 /api/room/list）→ 回车或点「搜索」。

      
点搜索结果 → 中间画出以该符号为中心的调用关系图；点结果右侧 ⧉ 链路 → 一次递归展开它调用的整条方法链。

      
按项目查询

      
Next.js / TS：符号名 getRoomList；接口 /api/video/audit → route.ts；页面 /video → page.tsx（忽略 (admin) 路由组）；动态段 /api/xxx/123 → 匹配 [id]；输入片段自动模糊匹配。

      
Go：直接搜索函数/方法名（Add、GetList），从 handler 点「⧉ 链路」展开调用链；无 URL 路由定位。

      
PHP / Laravel：搜索方法名（goodsBatch）；输入路由 URL（/api/group/multiGroup.json）→ 定位 Controller@method；部分片段自动模糊匹配路由。

      
自定义框架（如 youpai）：自动探测无需配置——识别 control/ + ctlXxx.php + funcXxx 约定，输入真实后台 URL（/youpai/groupMoney.html、/youpai/tv/room.html）直接定位。命名不规则的特例才在项目根 codegraph.route.json 的 overrides 里写一条。

      
多 git 项目（workspace）

      
聚合仓库模式（如 appwork）：一个根目录嵌套多个独立 git 仓库（modules/*、packages/*、services/ 各是独立 .git）。建索引前需在根目录建 codegraph.json 用 includeIgnored 显式包含嵌套仓库（codegraph 默认忽略它们），如 { "includeIgnored": ["modules/", "services/"] }。然后在聚合根目录 codegraph init + cgv view 一次即可定位所有子仓库代码。互不嵌套的独立项目才各自启动。

      
图怎么看

      
中间金色 = 当前选中的符号 · 左侧绿色 = 调用者（谁调用了它） · 右侧蓝色 = 被调用者（它调用了谁） · 虚线框 = 叶子节点，点击继续展开。

      
图交互

      
滚轮缩放 · 拖拽空白处平移 · 单击节点 展开它的调用关系 · 双击节点 以它为新中心重开 · 单击中心 右侧定位源码 · 左上角 + / − / ⟲ 缩放与复位 · 顶部 ↩ 撤销展开 可逐级回退。

      
左侧面板

      
📁 文件浏览：按文件列出符号，点文件看该文件全部符号，点符号画图。🔍 搜索结果：符号/接口 URL 的匹配结果，带类型标签，可直接跳转。

      
右侧源码

      
点中心节点或展开节点后显示对应源码。» 折叠面板，面板左边缘可拖拽调宽，长代码行可横向滚动，鼠标悬浮可看被截断的完整路径。

      
快捷键

      

        
/聚焦搜索框

        
u撤销最近一次展开

        
r重置画布与历史

        
Esc清除输入 / 关闭本窗口

      

      
其他功能

      
噪音节点开关：关闭时隐藏 node_modules、压缩文件、外部依赖等噪音。高亮搜索：输入关键词，图中匹配节点保持清晰、其余变暗。⭳ 导出：SVG / PNG / JSON / Mermaid 四种格式。

      
⇈ 上游链：以当前中心为终点，向上递归展开「谁调用了它」（影响面分析）；搜索结果的 ⧉ 按钮 Shift+点击效果相同。⇢ 路径：依次点两个节点，高亮它们之间的调用路径，Esc 退出。类型过滤 / 正则：搜索框右侧可按符号类型过滤、用正则匹配。

      
环形虚线边：橙色虚线 = 回边（调用环/回调）。右上角概览图：大图时显示 minimap，点击跳转。链接分享：当前图状态自动写入地址栏 hash，复制链接即可分享/刷新恢复。索引过期：检测到代码变更时顶部提示重新索引。
